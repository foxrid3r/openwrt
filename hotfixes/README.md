# Hotfixes

This directory contains narrowly scoped fixes that can be applied to an
installed custom image without performing a firmware upgrade.

Each hotfix has its own directory containing an application script and release
instructions. A hotfix changes the running configuration but does not change
the installed custom-image version. Apply only hotfixes whose prerequisites
match the router.
